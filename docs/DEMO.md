# Демонстрация для жюри — 5–7 минут

Используйте только собственный демонстрационный аккаунт и синтетические действия, не личный календарь другого человека. На https://quicklist-ai.com зарегистрируйтесь и подтвердите email своим паролем; публиковать пароль не нужно. Для локального demo предварительно выполните [setup](SETUP.md) и добавьте оригинал отдельно.

1. Покажите исходные1000 записей через поиск «Найди задачу про презентацию». Пометка source=dataset/type_inferred означает учебный источник, не действие пользователя.
2. Текстом: «В пятницу нужно отправить отчет»; при вопросе о текущей пятнице уточните дату, не скрывайте обоснованную неоднозначность.
3. «Добавь встречу с командой завтра в15:00» — проверьте карточку и дату.
4. «Что у меня сегодня?» и «Что запланировано на эту неделю?» — покажите список/planner.
5. «Я когда-то ставил задачу по договору, найди ее» — это поиск истории, не только последних карточек.
6. Микрофон: «Создай напоминание через полчаса проверить материалы». Остановите запись, проверьте STT transcript, отправьте один раз и посмотрите вычисленные дату/время. Ручное TTS — при разрешённом собственном бюджете.
7. «Поставь встречу с Иваном завтра» → вопрос → «В одиннадцать утра». Должна появиться одна запись, без потери контекста.
8. Дополнительная функция: отметьте собственную тестовую задачу выполненной или удалите с подтверждением. Не делайте destructive demo на dataset/личных данных другого owner.
9. При необходимости Google: подключите свой аккаунт через штатный OAuth. Предупреждение Google UNVERIFIED APP не скрывать. Подключение не включает sync автоматически; не экспортируйте все исходные события ради demo. Calendar demo необязателен для четырёх основных операций PDF.

Новые записи принадлежат только вошедшему пользователю. Чтобы показать multi-user, выйдите и войдите в другой собственный новый аккаунт: его исходный набор независим, новые личные записи первого не видны. Не передавайте чужую сессию и не просите публично чужой пароль.

Известные ограничения не прятать: платный AI требует API billing; одна выдача50; recurrence90дней без автопродления; публичная Google verification не подтверждена. [Матрица](GORKYCODE-COMPLIANCE.md).
